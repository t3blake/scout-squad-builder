Squad Zip Builder

Collect a few role details, then export a full squad package your CSAs can extract and point Scout to.

This is a personal/community scaffold generator. It is not an official Microsoft product and is not affiliated with or endorsed by Microsoft.

What this does

Scout squads help you organize specialist agents with clear boundaries, memory patterns, and compliance guardrails. This builder gives you a ready-to-extract squad package plus a copy/paste Scout import prompt.

Why teams use it

  • Faster onboarding for common work patterns.
  • Consistent guardrails from day one.
  • Flexible templates you can adapt without editing code.

Import steps

  1. Generate and extract the zip.
  2. If needed, run scripts/set-team-root.ps1 with your local path.
  3. Paste the prompt into your Scout skill flow.
  4. Start with Squad Lead and validate output against official docs.
