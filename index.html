Scout skill wrapper

Why this is useful: a named Scout skill gives users one stable command path (similar to a /squad pattern), so they do not have to remember setup details every session.

Example calls: /squad or /it-squad. Allowed characters are letters, numbers, and dashes.

Member roles

Why this matters: role coverage keeps work routed clearly (for example, research vs compliance vs planning) and improves output quality. You can edit default roles, change type, add new roles, and remove any role.

Remove warning behavior: deleting a required or suggested role prompts confirmation so users stay in control with guardrails.
